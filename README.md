# Nano Banana Prompt Studio v0.2

Professional AI visual content studio — from still image to motion video.

**Image**: Nano Banana 2 prompts | **Video**: Kling 3.0 + Veo 3 motion prompts | **Ads**: Complete TikTok/Reels workflow

## What This Plugin Does

Turn your ideas into production-ready prompts for the full content pipeline: generate a perfect still image with Nano Banana 2, then animate it into a motion video with Kling 3.0 or Veo 3 (with audio). Covers fashion, food, skincare, lifestyle, and commerce.

## The Pipeline

```
Your Idea → Nano Banana 2 (still image) → Kling 3.0 or Veo 3 (motion video) → TikTok/Reels
```

Choose Kling when you need precise camera control and physics (product spins, fashion walks).
Choose Veo 3 when you need audio (dialogue ads, ASMR unboxing, atmospheric brand films).
